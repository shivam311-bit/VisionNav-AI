# VisionNav-AI
VisionNav AI is a simulation-based autonomous robot navigation system that uses the A* pathfinding algorithm to calculate optimal paths, navigate grid-based environments, avoid obstacles, and support dynamic path replanning . Built with React, FastAPI, and Python, the project demonstrates intelligent navigation and real-time obstacle management.
# VisionNav AI 🤖

### Intelligent Autonomous Robot Navigation and Dynamic Obstacle Avoidance

VisionNav AI is a simulation-based project that demonstrates how an autonomous robot can find a path from a starting point to a destination while navigating around obstacles in a grid-based environment.

The project uses the **A* (A-star) pathfinding algorithm** to calculate a route and demonstrates how navigation can be updated when obstacles appear or the environment changes.

## Key Features

* 🗺️ Grid-based environment simulation
* 🧭 A* pathfinding for route calculation
* 🚧 Obstacle placement and management
* 🔄 Dynamic path replanning
* 🎯 Start and destination selection
* ⚡ Backend API integration
* 🖥️ Interactive React frontend
* 🐍 Python FastAPI backend

## Technology Stack

* **Frontend:** React, Vite
* **Backend:** Python, FastAPI
* **Pathfinding:** A* algorithm
* **Environment:** Grid-based navigation simulation

## Project Goal

The goal of VisionNav AI is to demonstrate how pathfinding algorithms can help autonomous navigation systems plan routes, respond to obstacles, and find alternative paths when the original route becomes blocked.

**Note:** This is currently a software simulation, not a physical robot. Obstacle detection is represented through the simulated environment rather than real-world camera or sensor input.
